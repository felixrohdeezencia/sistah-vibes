# Sistah Vibes · Website (draft)

Static one-pager for DJ, producer and festival host Sistah Vibes. No build step: `index.html` + `assets/`.

- Language: Spanish by default, English via the toggle or `?lang=en`
- Sound/theme: Roots (reggae/dancehall) by default, Afro (Afro House/Tech, Amapiano) via the toggle or `?sound=afro`
  — e.g. send Afro House bookers `…/?sound=afro&lang=en`
- Links (WhatsApp channel, SoundCloud embed, release links, Instagram live feed) live in `CONFIG` at the top of the script in `index.html`
- Press kits: `assets/press/`
